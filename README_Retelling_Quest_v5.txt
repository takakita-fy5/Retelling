Retelling Quest v5

【使い方】
1. GitHub Pages など HTTPS の場所に index.html を配置してください。
2. 先生モードで授業タイトル・教科書本文・生徒に見せるキーワードを入力します。
3. 「模範解答例の下書きを作る」を押すと、本文からキーワードを含む文（最大3文）を抜き出します。これは自動要約ではないため、自然なリテリング英文になるよう先生が編集してください。
4. 「授業設定を保存」を押します。
5. 生徒モードで2つのモードから選びます。
   - MODE 1：生徒が自分で書いた紙のメモを見ながら話す。ゲーム内に準備メモ欄はありません。
   - MODE 2：先生が指定したキーワードだけを画面に表示して話す。
6. 英語で話すか、文字起こし欄に直接入力します。
7. 発音・話しやすさを1〜5で自己評価（または先生が評価）し、採点します。

【採点について】
- 内容：指定キーワードの使用状況を参考にした簡易評価
- 語彙・文法/構成・伝わり方：語数、語彙の多様さ、文数などを使った参考評価
- 発音：生徒の自己評価または先生の評価を反映
- ブラウザ標準の音声認識は発音評価サービスではありません。音声認識のconfidenceも発音の正しさを保証しないため、自動発音採点とはしていません。
- 意味の一致、文法の正誤、発音の音素・イントネーションを自動で正確に評価するものではありません。

【プライバシー・動作】
- 音声データはアプリ内に保存しません。ブラウザの音声認識機能を利用します。
- 授業設定は同じブラウザのlocalStorageに保存します。
- マイク利用にはChrome/Edge等の対応ブラウザ、HTTPS接続、マイク許可が必要です。
- 音声認識が使えない場合も英文の直接入力で採点できます。
